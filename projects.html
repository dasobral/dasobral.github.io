01

Agent Trust

Agent systems / Research software

How can an agent’s authority remain coherent with the capabilities it exercises? An experimental research laboratory for Authorization–Capability Coherence.

Cryptographic agent principals, attenuated delegation, revocation, OpenMLS authorization domains, and authenticated invocation provenance make the question concrete in Rust and Python.

Experimental research software. Not production identity or authorization software.

02

OpenMLS QRNG

Quantum randomness / Rust library

A reusable bridge that supplies entropy from the QRNG Open API to OpenMLS through its OpenMlsRand interface.

HTTP, TLS, and mutual TLS modes support different integration environments, with health monitoring and fail-closed behavior when the entropy source is unavailable.

Integrates with the OpenMLS randomness interface; it does not replace every randomness path.

03

Portable Skills

Developer tools / Skills & plugins

Agent instructions are more useful when they can travel with the developer. Portable Skills maintains Agent Skills and Agent Plugins in a normalized source.

Adapters for Cursor and Codex handle environment-specific output, supported by validation, export, and installation tooling.

A portability workflow with explicit adapters; support depends on the target environment.

04

Codex Inspector

Observability / Local-first tooling

A local view into active OpenAI Codex CLI sessions, built to make their activity easier to inspect.

Process and session discovery feed normalized, redacted event storage in SQLite, with CLI summaries and a local dashboard for exploration.

Local observability tooling for Codex CLI sessions. Redaction is part of event handling, not a guarantee that all sensitive data can be identified.

Explore Codex Inspector ↗
05

QAOA Portfolio Optimizer

Scientific computing / Python & Rust

A laboratory for exploring portfolio optimization with the Quantum Approximate Optimization Algorithm.

Market data flows into a QUBO formulation and a PennyLane backend. Classical baselines, visualization, and reproducible benchmarks provide context for interpreting each experiment.

An experimental comparison framework. Results depend on the problem and configuration; no quantum advantage is claimed.

An introduction to post-quantum cryptography, developed as Spanish-language teaching material.

The course makes the subject accessible through material published on the web, with the source available for further exploration.

Educational material for building understanding of PQC.
