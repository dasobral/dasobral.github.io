Projects / Selected work

Selected work,
made concrete.

Software and research across cryptographic systems, quantum technologies, agent security, and scientific computing.

Each project makes its scope and limits explicit.

01

Agent Trust

Agent security / Rust & Python

An experimental laboratory for cryptographic agent principals, attenuated delegation, revocation, and authorization–capability coherence.

Research software for studying agent authority, not a production identity platform.

Explore Agent Trust ↗
02

PQC Auth API

Applied cryptography / Python & Rust

A reference authentication system that enrolls ML-DSA credentials, verifies signed server challenges through pluggable providers, and issues conventional sessions.

A security reference implementation with explicit threat-model and recovery boundaries, not a production identity provider.

03

OpenMLS QRNG

Quantum randomness / Rust

A reusable bridge from the QRNG Open API to OpenMLS randomness, with TLS/mTLS transport, health monitoring, and fail-closed entropy retrieval.

It replaces the OpenMLS randomness interface, not every randomness path in the cryptographic stack.

Explore OpenMLS QRNG ↗
04

Portable Skills

Agent tooling / Python

A portable source of Agent Skills and Plugins, with adapters that preserve one instruction set across different coding environments.

Explore Portable Skills ↗
05

QAOA Portfolio Optimizer

Quantum optimization / Python & Rust

A reproducible laboratory for QAOA portfolio formulations, classical baselines, benchmark matrices, and evidence-led comparison.

An experimental comparison framework; it makes no claim of quantum advantage.

Explore QAOA Portfolio ↗
06

A Predictable Darkness

Independent research / Computational physics

A reproducible research note on total solar eclipses over El Bierzo, combining verified ephemerides, computational reconstruction, uncertainty analysis, and publication-ready figures.

Common-Era results are numerically verified; ancient events are treated cautiously because of Delta-T uncertainty.

07

Post-Quantum Cryptography Course

Teaching / Spanish

An accessible Spanish-language introduction to post-quantum cryptography, published with its source material.
