2026 · Rust, Python · OpenMLS, SQLite

Agent Trust

Authority for AI agents that can be checked, not assumed.

When an agent acts for a user through other agents, ordinary authorization and group membership drift apart. Agent Trust is a laboratory that binds them: a durable kernel orders policy, delegation, release and revocation; a real OpenMLS adapter binds group admission to signed certificates; and an independent Python oracle replays every trace without importing the code it checks.

child(read) → parent(read,write) → WRITE   DENY
parent(read,write) → WRITE                ALLOW

Boundary Research software. The verifier fails closed, and it still reports full_lap_mls = false because full coupling to MLS isn’t proven yet.

2025 · C, OpenSSL 3 · UC3M

Hybrid QKD for TLS and IPsec

Getting pre-shared quantum keys through protocols built for key exchange.

QKD hands you keys in advance; TLS and IKEv2 expect to negotiate them. With the UC3M team I worked on QKD-KEM, an OpenSSL provider that carries QKD into TLS 1.3, including the stateful ETSI 004 interface most work skips, and then its IPsec counterpart, which runs QKD and post-quantum methods in parallel instead of in sequence. On real QKD hardware the parallel design avoided the multiplied latency of sequential hybrids.

Boundary Two peer-reviewed IEEE ISCC 2025 papers. The IPsec study is a preprint.

2026 · Rust · OpenMLS, rustls

openmls-qrand

Quantum randomness for group messaging, with no quiet fallback.

A small library that supplies OpenMLS with entropy from any QRNG Open API endpoint, such as Quside Entropy Core. It offers plain HTTP, TLS or mutual TLS, optional health polling, and it composes with existing OpenMLS crypto and storage instead of re-implementing them. If the source is unavailable, it fails. It never falls back to /dev/urandom.

Boundary It covers the OpenMLS randomness interface, not every random draw in the crypto stack beneath it.

Curso de Criptografía Post-Cuántica

The post-quantum migration, explained to the people who will do it.

A free 16-hour course: six topics from Shor’s algorithm to ML-KEM, ML-DSA, SLH-DSA, hybrid TLS and QKD. It includes five in-browser demos and five hands-on labs with liboqs, OpenSSL 3.5 and Qiskit, written in Spanish for engineers who need to migrate real systems.
